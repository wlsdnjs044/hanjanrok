# 한잔록 (盞錄)

홈카페 추출 기록 — 에스프레소·필터·커핑 로그와 레시피 북.
의존성 없는 단일 HTML 앱이고, 기록은 브라우저 localStorage에 저장된다.

**게시 주소** — https://claude.ai/code/artifact/b6ee0508-0fc1-4aba-8f52-fe1a105c8e27

## 파일

| 경로 | 설명 |
|---|---|
| `index.html` | **원본.** 앱 전체(CSS·JS·시드 데이터)가 들어 있다. 수정은 항상 여기서 한다. |
| `build-artifact.sh` | 원본을 아티팩트 게시용 조각으로 변환한다. |
| `build/` | 변환 결과물. 생성물이라 git에 넣지 않는다. |
| `*.mp3` | 배경음악 3곡. 게시할 때 첨부 파일로 함께 올린다. |

`index.html`은 그 자체로 브라우저에서 바로 열린다. 고친 내용을 확인할 때는 파일을 직접 열어보면 된다.

## 수정하고 다시 게시하기

```bash
# 1. index.html 수정 후
./build-artifact.sh
```

그다음 Claude에게 `build/hanjanrok-artifact.html`을 위 주소로 다시 게시해 달라고 하면 된다.
mp3 3개(`bgm.mp3`, `night-dose.mp3`, `fading-into-the-room.mp3`)를 첨부 파일로 같이 올려야
음악 재생이 동작한다.

같은 주소로 갱신해야 기존 링크가 유지된다. 새로 게시하면 별개의 아티팩트가 생긴다.

### 변환 과정에서 덜어내는 것

아티팩트는 게시 시점에 문서 껍데기를 직접 씌우므로, 아래는 스크립트가 제거한다.

- `<!DOCTYPE>` · `<html>` · `<head>` · `<body>` — 남아 있으면 게시가 거부된다
- `<meta>` (charset·viewport·theme-color 등) — 호스트가 넣어준다
- PWA manifest와 아이콘 3종 — 아티팩트는 홈 화면 설치 대상이 아니다

`<html lang="ko">`가 사라지는 대신 스크립트 한 줄로 런타임에 보정한다.
`index.html` 쪽은 건드리지 않으므로 단독 실행 기능은 그대로 남는다.

## 아티팩트 환경에서의 제약

뷰어가 샌드박스라 아래 두 가지가 원래대로 동작하지 않는다. 둘 다 앱에 이미 있는
폴백으로 흘러가므로 기능 자체는 쓸 수 있다.

- **CSV 내보내기** — 자동 다운로드가 차단된다. 대신 복사 패널이 열리므로 내용을
  복사해 `.csv`로 저장하면 된다.
- **레시피 공유 카드** — 자동 저장이 차단된다. 이미지가 화면에 뜨면 길게 눌러 저장한다.

클립보드 복사도 막힐 수 있는데, 실패하면 직접 선택해 복사하라는 안내가 뜬다.

## 기록 데이터

localStorage는 **주소(오리진)마다 따로 논다.** 기기나 게시 위치가 바뀌면 기록이
자동으로 따라오지 않으므로 앱의 동기화 기능을 쓴다.

1. 기존 기기에서 하단 **🔄 기기 간 동기화** → **코드 복사** (`BA1:`로 시작)
2. 새 기기에서 같은 창을 열고 붙여넣기 → **합치기**

## 이력

이 저장소는 원래 GitHub Pages(`wlsdnjs044.github.io/hanjanrok`)로 서빙했고,
지금은 아티팩트로 옮겼다. `index.html`에 남아 있는 PWA manifest와 아이콘은
그 시절의 흔적이며, 단독 실행 시에는 여전히 유효하다.

변경 이력은 앱 하단의 버전 버튼에서 볼 수 있다 (`index.html`의 `CHANGELOG` 배열).

## 재디자인

`design/`에 재디자인 아트보드 소스가 들어 있다. 아트보드마다 한 파일이고,
`canvas.json`이 캔버스 배치와 설명 메모를 담는다.

**확정안** — A 계기판 구조에 C 산점도를 합친 구성. 위에서부터
최근 추출 판독(압력 곡선 + 수치 6칸) → 샷·푸어 산점도 → 요약 4칸 → 최근 기록 표.

| 파일 | 화면 |
|---|---|
| `Main.dc.html` | 데스크탑 1440×1240 |
| `Mobile.dc.html` | 모바일 390×1820 |

색상은 아트보드 위 칩에서 고른다. 구조와 타이포는 그대로 두고 색만 바뀐다.

| 팔레트 | 바탕 | 강조 |
|---|---|---|
| 계기판 · 흑연 | `#101319` | `#E8A33D` |
| 활판 · 종이 | `#F5F1E8` | `#B8402C` |
| 좌표 · 모눈 | `#FBFBFC` | `#2F6FEB` |

선택되지 않은 B 활판 · C 좌표 원안은 캔버스 2쪽에 남겨 두었다
(`BDesktop` · `BMobile` · `CDesktop` · `CMobile`).
